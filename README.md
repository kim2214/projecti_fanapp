# Project I Fan App

버츄얼 아이돌 그룹 **프로젝트아이(Project I)** 의 비공식 팬 어플리케이션입니다.

> 이 앱은 팬이 제작한 비공식 어플리케이션이며, 프로젝트아이 공식과는 무관합니다.

---

## 소개

Project I Fan App은 프로젝트아이 소속 그룹인 **허니즈(Honeyz)** 와 **아카시아(Acaxia)** 의 팬들을 위한 모바일 어플리케이션입니다. 멤버들의
스케줄, SNS, 라이브 방송 정보를 한 곳에서 확인하고, 음악을 감상할 수 있습니다.

---

## 주요 기능

### 스케줄 확인

- 각 멤버의 방송 스케줄을 확인할 수 있습니다.
- 그룹별(허니즈/아카시아) 스케줄을 분류하여 볼 수 있습니다.

### 멤버 정보

- 각 멤버의 프로필 정보를 확인할 수 있습니다.
- SNS 링크 (X/Twitter, YouTube) 바로가기를 제공합니다.
- 치지직(Chzzk) 라이브 채널 바로가기를 제공합니다.
- 실시간 라이브 방송 여부를 확인할 수 있습니다.

### 음악 감상

- 프로젝트아이 소속 멤버들의 음악을 감상할 수 있습니다.
- 그룹별 음악 필터링 기능을 제공합니다.
- 백그라운드 재생을 지원합니다.

### 즐겨찾기

- 좋아하는 음악을 즐겨찾기에 추가할 수 있습니다.
- 즐겨찾기한 음악을 별도 탭에서 관리할 수 있습니다.
